# novel-down 依赖

# ⚠ 要注意「下限」与「可复现」是两件事（审计 #5，2026-09-22）：
#   本文件只给**下限**，适合「我就要能跑起来」的场景；
#   要**复现构建**（尤其是出 exe / 复现某个 tag 的产物）请用锁文件：
#       pip install -r requirements.lock
#   锁文件里的版本=发布版 exe 实际链进去的版本。
#
# 运行期只需这两个（EPUB/HTML 导出为纯标准库实现，不依赖 ebooklib/pandoc）
requests>=2.31
beautifulsoup4>=4.12

# 建议安装：bs4 的快速解析器（缺失时自动回退 Python 内置 html.parser）
lxml>=5.0

# 可选：字体反爬解码（番茄小说这类站点需要）——不装只影响该类站点
# fontTools 读字体轮廓，brotli 读 woff2 时必需
# fontTools>=4.50
# brotli>=1.1

# 可选：浏览器路由（目录靠 JS 渲染的站点）——不装只影响该类站点
# 装完还需下载内核：python -m playwright install chromium
# playwright>=1.40

# 可选但**强烈建议**（配浏览器路由用）：快速拆除浏览器进程树。
# 本机实测 Playwright 的优雅拆除极慢（browser.close() 47.8~50.4s / pw.stop() 33.6~36.0s），
# 装上 psutil 后改为「先杀自己拉起的进程树再 pw.stop()」，实测 0.00s + 0.04s，
# 残留 playwright 子进程 0（豆瓣专栏 3 章：61.9s → 13.3s）。
# 没装则自动退回优雅拆除，只是慢。识别边界见 noveldown/browser.py 的 _kill_subprocess_tree。
# psutil>=5.9

# 可选：TLS 指纹伪装（--curl-cffi）
# curl_cffi>=0.7
