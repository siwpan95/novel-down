# novel-down v0.8.38

规则驱动的网络小说离线阅读工具（**仅抓取各站点的免费章节**）。

本版新增 **Tkinter 图形界面**（此前只有命令行），并提供 Windows 便携版可执行程序。

---

## 系统要求

- **Windows 10 / 11（64 位）**
- 无需安装 Python —— 便携版已自带运行环境
- 用源码运行则需要 **Python 3.11+**（开发环境为 3.14.7）

## 安装步骤

**推荐：便携版（免安装）**

1. 下载 `noveldown-0.8.38-portable-win64.zip`，解压到任意目录；
2. **命令行版**：在该目录打开终端，执行
   ```
   noveldown.exe --help
   noveldown.exe sites                       :: 看有哪些站点规则
   noveldown.exe fetch "<书籍URL>"            :: 抓取并导出
   ```
3. **图形界面版**：下载 `noveldown-0.8.38-gui-win64.zip`，解压后**双击 `noveldown-gui.exe`**，
   在窗口里选站点 → 粘 URL → 点「开始抓取」。

**单文件版**：`noveldown-onefile.exe` 免解压直接跑。
⚠ 但每次启动要解包 + 被安全软件实时扫描，**实测启动约 47 秒**（便携版目录版只要约 1.4 秒），
所以**只推荐偶尔拿到别的机器上跑一下**的场景。

## 本版新增

### 图形界面（`noveldown/gui.py`，零第三方依赖）

选站点（161 条规则，可搜索）→ 粘 URL → 抓取（实时日志 + 进度条）→ 勾选导出格式 → 打开输出目录。
选中站点会**自动把该站的示例地址填进 URL 框**。抓取在后台线程里跑，界面不卡死；
「停止」会**保存断点**，下次点「开始抓取」即续爬。

### 发行版构建体系（`packaging/`）

`build.py` 一键构建（`--portable` / `--gui` / `--zip` / `--msi` / `--all`），
含 5 个实测踩坑的说明，详见 `packaging/README.md`。

## 已知限制（如实列出）

1. **本版不含 MSI / EXE 安装器**。构建环境限制（详见下），便携版即「解压即用」，
   不想用便携版可在有 Inno Setup 的机器上编译仓库里的 `packaging/inno.iss`。
2. **发行版是最小依赖**：**不含**浏览器路由（目录靠 JS 渲染的站点，如起点）、
   **不含**字体反爬解码（番茄小说这类）、不含 TLS 指纹伪装。
   需要这些能力请用源码方式运行（`pip install -r requirements.txt`）。
3. **单文件版启动很慢**（约 47 秒，见上）。
4. 站点规则会随站点改版失效 —— 遇到失败可用 `probe` 子命令定位，或用
   `tools/scan_mirrors.py` 重扫。
