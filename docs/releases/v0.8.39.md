# novel-down v0.8.39

规则驱动的网络小说离线阅读工具（**仅抓取各站点的免费章节**）。

⚠ **这是一个修复版**：修掉了 v0.8.38 里两个必现缺陷（详见「本版修了什么」）。
**如果你下载过 v0.8.38，请改用本版。**

---

## 系统要求

- **Windows 10 / 11（64 位）**
- 无需安装 Python —— 便携版已自带运行环境
- 用源码运行则需要 **Python 3.11+**（开发环境为 3.14.7）

## 本版修了什么

### 🔴 图形界面版导出必崩（v0.8.38 实测复现）

> `AttributeError: 'list' object has no attribute 'split'`

根因是**两个错叠在一起**：内部默认配置里的导出格式是**列表**、代码却按**字符串**切；
更隐蔽的是格式参数**压根没传到导出层**，等于你在界面上勾选的格式被静默忽略。
本版改为显式传递，并补了回归测试。

### 🔴 输出目录路径穿越（安全，CWE-22）

原来把**网页返回的书名**直接当作输出目录名 —— 恶意或被劫持的镜像站可以让成品被写到
你指定的 `--out` 目录**之外**；此外，书名里含 `?` `*` `|` 等 Windows 非法字符时，
**连目录都建不出来**（这条不需要任何攻击者就会遇到）。
本版统一走净化函数，并**额外断言目录不会越界**（净化是概率性的，断言才是兜底）。

### 🟠 其他

- 消除了一处 `SyntaxWarning`（未来 Python 版本会升级为错误）。
- 新增 **10 个**导出路径安全测试用例。

## 安装步骤

**推荐：便携版（免安装）**

1. `noveldown-0.8.39-portable-win64.zip` → 解压到任意目录，命令行执行：
   ```
   noveldown.exe --help
   noveldown.exe sites                    :: 看有哪些站点规则
   noveldown.exe fetch "<书籍URL>"         :: 抓取并导出
   ```
2. **图形界面版**：`noveldown-0.8.39-gui-win64.zip` → 解压后**双击 `noveldown-gui.exe`**，
   选站点 → 粘 URL → 点「开始抓取」。

**单文件版**：`noveldown-onefile.exe` 免解压直接跑。
⚠ 每次启动要解包 + 被安全软件实时扫描，**实测启动约 40 秒**（便携版目录版只要约 1.4 秒），
只推荐偶尔拿到别的机器上跑一下的场景。

## 已知限制（如实列出）

1. **本版不含 MSI / EXE 安装器**。构建环境有限制（见 `packaging/README.md`），
   便携版即「解压即用」；想要标准安装器可在有 Inno Setup 的机器上编译仓库里的 `packaging/inno.iss`。
2. **发行版是最小依赖**：**不含**浏览器路由（目录靠 JS 渲染的站点，如起点）、
   **不含**字体反爬解码（番茄小说这类）、不含 TLS 指纹伪装。
   需要这些能力请用源码方式运行（`pip install -r requirements.txt`）。
3. **单文件版启动很慢**（约 40 秒，见上）。
4. 上线前全检（`deliverables/gstack/launch-check-noveldown-2026-09-22.md`）里
   **其余中低优先级项尚未处理**：图形界面「停止」按钮的语义、
   目录解析失败时静默 0 章、打包脚本未纳入仓库门禁扫描、依赖未钉精确版本等。
   均**不阻塞**本版使用，会在后续版本处理。
5. 站点规则会随站点改版失效 —— 遇到失败可用 `probe` 子命令定位。
